# DigiVitrine Lomé

> L'inclusion numérique au service des artisans locaux

DigiVitrine Lomé est une plateforme numérique solidaire qui donne aux artisans
et micro-entrepreneurs de Lomé une vitrine en ligne : profil, services,
réalisations, localisation et moyens de contact (appel, WhatsApp).

## État du projet

En cours de conception (Phase 4 : mise en place de l'environnement).

## Structure du dépôt

| Dossier    | Contenu                                        |
|------------|------------------------------------------------|
| `backend/` | API REST Laravel + administration Filament     |
| `app/`     | Application Flutter (Android, Windows)         |
| `docs/`    | Cahier des charges, UML, base de données, API  |
| `infra/`   | Docker, déploiement, sauvegardes               |

## Stack technique

Flutter · Laravel 13 · Filament v5 · PostgreSQL · Docker · GitHub Actions
